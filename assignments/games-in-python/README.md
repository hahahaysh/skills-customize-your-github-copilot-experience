
# 📘 Assignment: Games in Python

## 🎯 Objective

Build a simple word-guessing game in Python using strings, loops, conditionals, and user input while practicing core programming logic.

## 📝 Tasks

### 🛠️ Build the Game Setup

#### Description
Create a game where the player tries to guess a hidden word one letter at a time before running out of attempts.

#### Requirements
Completed program should:

- Choose a random word from a list of predefined words
- Display the hidden word as underscores or blanks for each letter
- Ask the player to enter one letter at a time
- Reveal matching letters in the correct positions
- Keep track of guessed letters so the player does not repeat choices

### 🛠️ Track Progress and End Conditions

#### Description
Add the logic that tracks mistakes, checks for wins or losses, and ends the game with a clear result.

#### Requirements
Completed program should:

- Track the number of incorrect guesses remaining
- Reduce attempts when the player guesses a wrong letter
- End the game when the player correctly guesses the word or runs out of attempts
- Display a clear win or lose message at the end
- Include simple game output such as the current progress and remaining attempts after each guess
