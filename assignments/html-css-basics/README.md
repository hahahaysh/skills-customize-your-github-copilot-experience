# 📘 Assignment: HTML & CSS Basics

## 🎯 Objective

Build a simple personal webpage using HTML and CSS. Students will learn how to structure content, apply styles, and create a clean layout that can be opened in a browser.

## 📝 Tasks

### 🛠️ Build the Page Structure

#### Description
Create a basic webpage that includes a heading, short introduction, and a few sections such as interests or favorite activities.

#### Requirements
Completed program should:

- Use semantic HTML elements such as `header`, `main`, `section`, and `footer`
- Include a title and a short paragraph introducing the student or project
- Add at least three content sections, such as About Me, Skills, and Hobbies
- Use meaningful text and a clear page layout

### 🛠️ Style the Page

#### Description
Apply CSS to make the page visually appealing and easy to read.

#### Requirements
Completed program should:

- Set colors, spacing, and font styles for the page
- Use a simple layout with centered content or columns
- Add padding and margins so the page feels clean and organized
- Ensure the page is readable and looks polished on a browser screen

### 🛠️ Add a Small Interactive Touch

#### Description
Include one small visual effect to make the page feel more dynamic.

#### Requirements
Completed program should:

- Add one hover effect, button style, or color transition
- Keep the interaction simple and beginner-friendly
- Make sure the change is visible when the user moves their mouse over the element
